# 🌐 Про фронтенд в этом приложении

## 🎯 Главное

**Это SSR (Server-Side Rendering) приложение** - фронтенд и бэкенд работают **вместе** на одном сервере.

## 📍 Где находится фронтенд?

### В коде:
- **Компоненты:** `packages/evershop/src/components/`
  - `frontStore/` - компоненты для магазина
  - `admin/` - компоненты для админки
  - `common/` - общие компоненты

- **Страницы:** `packages/evershop/src/modules/*/pages/`
  - `frontStore/` - страницы магазина
  - `admin/` - страницы админки

### После сборки:
- Всё компилируется в один сервер
- Фронтенд рендерится на сервере
- Нет отдельного фронтенда - всё в одном приложении

## 🔄 Как это работает?

1. **Пользователь открывает сайт** → Запрос идет на Express сервер
2. **Сервер рендерит React компоненты** → Генерирует HTML на сервере
3. **HTML отправляется браузеру** → Пользователь видит страницу
4. **JavaScript загружается** → Страница становится интерактивной

## 🌐 Где доступен фронтенд?

После успешного запуска приложения:

- **Главная страница:** `https://your-app.up.railway.app`
- **Админ-панель:** `https://your-app.up.railway.app/admin`
- **API:** `https://your-app.up.railway.app/api/*`

**Всё на одном домене!** Нет отдельного фронтенда.

## ⚠️ Важно понимать

- ❌ **НЕЛЬЗЯ** разделить на Netlify (фронт) + Railway (бэкенд)
- ✅ **ВСЁ** работает на Railway - это правильный подход для SSR
- ✅ Фронтенд и бэкенд - это **одно приложение**

## 🎨 Структура фронтенда

```
packages/evershop/src/
├── components/          # React компоненты
│   ├── frontStore/      # Компоненты магазина
│   ├── admin/           # Компоненты админки
│   └── common/          # Общие компоненты
├── modules/             # Модули приложения
│   └── */pages/         # Страницы (фронтенд + бэкенд вместе)
└── lib/                 # Библиотеки
```

## 🚀 После настройки БД

1. Приложение запустится
2. Откройте домен Railway
3. Фронтенд будет доступен сразу
4. Никакой дополнительной настройки не нужно!
