### 🔴 КРИТИЧЕСКОЕ ИСПРАВЛЕНИЕ #1: Компиляция postgres-query-builder

**Проблема:**
```
Error: Cannot find package '/app/node_modules/@evershop/postgres-query-builder/dist/index.js'
```

**Причина:** Пакет `@evershop/postgres-query-builder` не компилировался перед компиляцией `evershop`.

**Решение:**
Добавлена команда `npm run compile:db` в Dockerfile перед `npm run compile`:

```dockerfile
# Сначала компилируем postgres-query-builder, затем evershop, затем собираем приложение
# Важно: postgres-query-builder должен быть скомпилирован ПЕРЕД evershop, так как evershop зависит от него
RUN npm run compile:db && npm run compile && npm run build
```

**Файл:** `Dockerfile` (строка 30)
**Коммит:** `6901b67`

### 🟡 ИСПРАВЛЕНИЕ #2: Синтаксис COPY в Dockerfile

**Проблема:** Неправильный синтаксис команды COPY для копирования package.json файлов.

**Решение:**
```dockerfile
# БЫЛО (неправильно):
COPY --from=builder /app/package.json /app/package-lock.json ./

# СТАЛО (правильно):
COPY --from=builder /app/package*.json ./
```

**Файл:** `Dockerfile` (строка 45)
**Коммит:** `772d94d`

---

### 🟡 ИСПРАВЛЕНИЕ #3: Конфликт startCommand в railway.json

**Проблема:** `startCommand` в railway.json конфликтовал с CMD в Dockerfile.

**Решение:**
Удален `startCommand` из railway.json. Теперь используется только CMD из Dockerfile.

**Файл:** `railway.json`
**Коммит:** `772d94d`
