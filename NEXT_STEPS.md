# 🎯 Следующие шаги после деплоя

## ❌ Текущая проблема

Из логов видно:
```
AggregateError [ECONNREFUSED]
```

**Причина:** База данных не подключена, хотя переменные окружения установлены.

**Возможные причины:**
1. Значения переменных не совпадают с PostgreSQL сервисом
2. PostgreSQL сервис не запущен
3. Переменные не применены (нужен перезапуск)
4. Проблема с SSL подключением

## ✅ Что нужно сделать

### 1. 🔌 Настроить подключение к базе данных

#### Шаг 1: Проверить, что PostgreSQL сервис создан

1. Откройте ваш проект в Railway
2. Убедитесь, что есть сервис **PostgreSQL**
3. Если его нет - создайте: **"+ New"** → **"Database"** → **"Add PostgreSQL"**

#### Шаг 2: Получить данные подключения

1. Откройте сервис **PostgreSQL** (не приложение!)
2. Перейдите во вкладку **"Variables"**
3. Вы увидите автоматически созданные переменные:
   - `PGHOST`
   - `PGPORT`
   - `PGDATABASE`
   - `PGUSER`
   - `PGPASSWORD`

#### Шаг 3: Настроить переменные окружения в приложении

1. Вернитесь к сервису **приложения** (не PostgreSQL)
2. Перейдите во вкладку **"Variables"**
3. Добавьте следующие переменные:

**Обязательные переменные:**

| Переменная | Значение | Как получить |
|------------|----------|--------------|
| `DB_HOST` | Значение из `PGHOST` | Скопируйте из PostgreSQL сервиса → Variables → PGHOST |
| `DB_PORT` | Значение из `PGPORT` | Скопируйте из PostgreSQL сервиса → Variables → PGPORT |
| `DB_NAME` | Значение из `PGDATABASE` | Скопируйте из PostgreSQL сервиса → Variables → PGDATABASE |
| `DB_USER` | Значение из `PGUSER` | Скопируйте из PostgreSQL сервиса → Variables → PGUSER |
| `DB_PASSWORD` | Значение из `PGPASSWORD` | Скопируйте из PostgreSQL сервиса → Variables → PGPASSWORD |
| `DB_SSLMODE` | `require` | Введите вручную |
| `NODE_ENV` | `production` | Введите вручную |

**Как скопировать значения:**
1. Откройте PostgreSQL сервис → Variables
2. Нажмите на значок "глаз" рядом с `PGHOST` чтобы увидеть значение
3. Скопируйте значение
4. Вернитесь к приложению → Variables
5. Нажмите **"+ New Variable"**
6. Имя: `DB_HOST`, Значение: вставьте скопированное значение
7. Повторите для всех переменных

#### Шаг 4: Перезапустить приложение

После добавления всех переменных:
1. Railway автоматически перезапустит приложение
2. Или нажмите **"Redeploy"** вручную
3. Проверьте логи - ошибка `ECONNREFUSED` должна исчезнуть

### 2. 🌐 Про фронтенд

**Важно:** Это **SSR (Server-Side Rendering)** приложение!

**Что это значит:**
- ✅ Фронтенд и бэкенд работают **вместе** на одном сервере
- ✅ React компоненты рендерятся **на сервере**
- ✅ Нет отдельного фронтенда - всё в одном приложении
- ✅ Фронтенд доступен по тому же домену, что и бэкенд

**Где находится фронтенд:**
- Фронтенд код: `packages/evershop/src/components/`
- Фронтенд страницы: `packages/evershop/src/modules/*/pages/`
- После сборки: всё компилируется в один сервер

**Как получить доступ:**
1. После настройки БД и успешного запуска
2. Откройте домен Railway (например: `your-app.up.railway.app`)
3. Фронтенд будет доступен по этому же адресу
4. Админ-панель: `your-app.up.railway.app/admin`

## 🆘 Если что-то не работает

### Проблема: Все еще ECONNREFUSED

**Решение:**
1. Проверьте, что все переменные `DB_*` установлены
2. Убедитесь, что значения скопированы правильно (без лишних пробелов)
3. Проверьте, что `DB_SSLMODE=require` установлен
4. Убедитесь, что PostgreSQL сервис запущен

### Проблема: Authentication failed

**Решение:**
1. Проверьте, что `DB_USER` и `DB_PASSWORD` скопированы правильно
2. Убедитесь, что используете значения из PostgreSQL сервиса, а не старые

### Проблема: Сайт не открывается

**Решение:**
1. Проверьте, что приложение запущено (нет ошибок в логах)
2. Убедитесь, что домен сгенерирован в Railway
3. Проверьте, что порт 3000 открыт
