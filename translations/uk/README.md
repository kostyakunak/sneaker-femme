# Українська локалізація

Українська мова додана до платформи. Для активації:

## Як активувати українську мову

1. Відкрийте файл `config/default.json` в корені проекту

2. Змініть значення `language` з `"en"` на `"uk"`:

```json
{
  "shop": {
    "currency": "UAH",
    "language": "uk",
    "weightUnit": "kg",
    "timezone": "Europe/Kiev"
  }
}
```

3. Перезапустіть сервер:

```bash
npm run dev
# або
npm start
```

## Структура перекладів

Українська локалізація включає:

- **general.csv** - загальні переклади
- **account.csv** - переклади для акаунту користувача
- **catalog.csv** - переклади для каталогу товарів
- **checkout.csv** - переклади для оформлення замовлення
- **paypal.csv** - переклади для PayPal

## Додаткові налаштування

Рекомендовано також змінити:
- `currency` на `"UAH"` (українська гривня)
- `timezone` на `"Europe/Kiev"` (київський час)
