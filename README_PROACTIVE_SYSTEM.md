# 🛡️ Система проактивных проверок - Быстрый старт

## 🎯 Что это?

Система, которая **предугадывает проблемы до деплоя**, вместо того чтобы ждать ошибок из логов Railway.

## 🚀 Быстрый старт

### 1. Перед каждым коммитом

```bash
npm run pre-deploy-check
```

Если есть ошибки - **НЕ КОММИТЬТЕ** до исправления!

### 2. Анализ зависимостей

```bash
npm run analyze-deps
```

Показывает правильный порядок компиляции пакетов.

### 3. Полная проверка перед деплоем

```bash
# 1. Проверка структуры и зависимостей
npm run pre-deploy-check

# 2. Анализ зависимостей
npm run analyze-deps

# 3. Проверка переменных окружения (вручную в Railway)
# 4. Деплой
git push
```

## 📋 Что проверяется автоматически?

### ✅ Структура проекта
- Все workspace пакеты на месте
- Все необходимые файлы существуют
- Конфигурационные файлы присутствуют

### ✅ Зависимости
- Правильные зависимости между пакетами
- Порядок компиляции соответствует зависимостям
- Нет циклических зависимостей

### ✅ Dockerfile
- Правильный порядок компиляции
- Все файлы копируются
- CMD/ENTRYPOINT присутствует

### ✅ Конфигурация
- .swcrc файлы на месте
- tsconfig.json валиден
- .dockerignore настроен

## 🎯 Преимущества

1. **Экономия времени** - находим проблемы за секунды, а не минуты
2. **Меньше стресса** - не нужно ждать деплоя и проверять логи
3. **Автоматизация** - можно добавить в CI/CD или git hooks
4. **Документация** - явно видно, что проверяется

## ⚙️ Интеграция с Git Hooks

Добавьте в `.husky/pre-commit`:

```bash
#!/bin/sh
npm run pre-deploy-check
```

Или используйте husky:

```json
{
  "husky": {
    "hooks": {
      "pre-commit": "npm run pre-deploy-check"
    }
  }
}
```

## 🔧 Кастомизация

Чтобы добавить свою проверку, откройте `scripts/pre-deploy-check.js`:

```javascript
function checkMyCustomThing() {
  success('Проверка моей вещи...');
  
  if (somethingWrong) {
    error('Что-то не так');
  } else {
    success('Все хорошо');
  }
}

// Добавьте в main()
checkMyCustomThing();
```

## ❓ FAQ

**Q: Нужно ли запускать перед каждым коммитом?**
A: Рекомендуется, но не обязательно. Обязательно перед деплоем.

**Q: Можно ли использовать в CI/CD?**
A: Да! Добавьте `npm run pre-deploy-check` в ваш CI pipeline.

**Q: Что делать, если проверка нашла ошибку?**
A: Исправьте ошибку перед коммитом/деплоем.

**Q: Можно ли отключить некоторые проверки?**
A: Да, отредактируйте `scripts/pre-deploy-check.js` и закомментируйте ненужные проверки.

## 🆘 Проблемы?

Если скрипт не работает:
1. Убедитесь, что Node.js >= 18
2. Убедитесь, что все зависимости установлены: `npm install`
3. Проверьте права на выполнение: `chmod +x scripts/*.js`
