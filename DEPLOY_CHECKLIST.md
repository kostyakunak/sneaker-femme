# ✅ Чек-лист перед деплоем на Railway

## 🔍 Перед каждым коммитом

### 1. Проверка файлов
- [ ] Все изменения закоммичены (`git status` должен быть чистым)
- [ ] `Dockerfile` корректен и проходит локальную проверку
- [ ] `.dockerignore` настроен правильно
- [ ] `railway.json` настроен правильно

### 2. Проверка Dockerfile
- [ ] Синтаксис COPY команд корректен
- [ ] Все необходимые файлы копируются
- [ ] Порты настроены правильно (EXPOSE 3000)
- [ ] CMD команда указана правильно

### 3. Проверка переменных окружения в Railway
- [ ] `DB_HOST` установлен (из PGHOST)
- [ ] `DB_PORT` установлен (из PGPORT)
- [ ] `DB_NAME` установлен (из PGDATABASE)
- [ ] `DB_USER` установлен (из PGUSER)
- [ ] `DB_PASSWORD` установлен (из PGPASSWORD)
- [ ] `DB_SSLMODE=require` установлен
- [ ] `NODE_ENV=production` установлен
- [ ] `PORT=3000` установлен (опционально, Railway устанавливает автоматически)

## 🚨 Частые проблемы и решения

### Проблема: Ошибка сборки Docker
**Причина:** Неправильный синтаксис в Dockerfile
**Решение:** 
- Проверьте синтаксис COPY команд
- Убедитесь, что все пути правильные
- Проверьте, что все файлы существуют

### Проблема: Приложение не запускается
**Причина:** Отсутствуют переменные окружения или неправильные значения
**Решение:**
- Проверьте все переменные DB_* в Railway
- Убедитесь, что PostgreSQL сервис запущен
- Проверьте логи в Railway

### Проблема: Ошибка подключения к БД
**Причина:** Неправильные переменные окружения или отсутствие DB_SSLMODE
**Решение:**
- Убедитесь, что все DB_* переменные скопированы из PostgreSQL сервиса
- Проверьте, что `DB_SSLMODE=require` установлен
- Проверьте, что значения скопированы правильно (без лишних пробелов)

### Проблема: Бесконечные перезапуски
**Причина:** Приложение падает при старте
**Решение:**
- Проверьте логи в Railway
- Убедитесь, что все зависимости установлены
- Проверьте, что сборка прошла успешно
- Убедитесь, что все необходимые файлы скопированы

## 📝 Команды для проверки

### Локальная проверка Dockerfile
```bash
cd evershop-dev
docker build -t evershop-test .
docker run -p 3000:3000 evershop-test
```

### Проверка git статуса
```bash
git status
git diff
```

### Проверка Railway логов
```bash
railway logs
```

## ⚠️ Важно помнить

1. **Никогда не коммитьте `.env` файл**
2. **Всегда проверяйте логи в Railway после деплоя**
3. **Убедитесь, что все переменные окружения установлены ПЕРЕД первым деплоем**
4. **Railway автоматически перезапускает приложение при каждом push в main ветку**
5. **Если деплой не работает, проверьте логи СНАЧАЛА, прежде чем делать новый коммит**

## 🔄 Процесс деплоя

1. ✅ Проверьте чек-лист выше
2. ✅ Закоммитьте изменения: `git add . && git commit -m "описание изменений"`
3. ✅ Запушьте в репозиторий: `git push`
4. ✅ Подождите автоматического деплоя в Railway (обычно 2-5 минут)
5. ✅ Проверьте логи в Railway
6. ✅ Проверьте работу приложения по домену

## 🆘 Если деплой не работает

1. **НЕ ДЕЛАЙТЕ НОВЫЙ КОММИТ СРАЗУ!**
2. Проверьте логи в Railway
3. Найдите конкретную ошибку
4. Исправьте проблему локально
5. Протестируйте локально (если возможно)
6. Только после этого делайте коммит
